## My Favorite Series: *Avatar: The Last Airbender*

![Series](https://img.shields.io/badge/Favorite%20Series-Avatar-blue)

**Avatar: The Last Airbender** is an animated series that aired on Nickelodeon from 2005 to 2008. It follows a young Avatar who must master all four elements and end a century-long war.

> "Water. Earth. Fire. Air." Four nations, one Avatar.

### Main Characters

1. **Aang** – the Avatar and an Airbender
2. **Katara** – a Waterbender
3. **Sokka** – a warrior and strategist
4. **Toph** – an Earthbender
5. **Zuko** – a Firebender
